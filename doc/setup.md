# Конфигурация и данные

Публичная версия содержит исходники, тесты и обезличенные примеры XLSX.
`defaults.json`, `.env`, каталог `secrets/`, персональные `templates/*.xlsx`,
базы и резервные копии исключены из Git. `.env.example` и `defaults.example.json`
публикуются. В образ Docker копируются только примеры настроек и шаблонов;
рабочие файлы подключаются при запуске отдельными томами только для чтения.

Порядок установки описан в README. Реквизиты загружаются из `defaults.json`
только при первом создании базы. Дальнейшие изменения выполняются в настройках
бота и сохраняются в SQLite. Замена defaults.json не меняет уже сохранённые
настройки. Не удаляйте базу для смены реквизитов: она содержит архив документов.

Следующий номер может быть любым положительным целым, включая повторный.
Для уже оформленного листа сохраняется его номер. Новые архивные версии
имеют отдельные ID; старые файлы остаются неизменными.

Подпись в демонстрационных шаблонах заменена прозрачным изображением.
Для своей подписи замените этот рисунок в личных копиях шаблонов средствами
Excel, сохранив расположение ячеек и структуру листа. Область печати и рисунок
следует проверить в программе, в которой будут использоваться документы.
